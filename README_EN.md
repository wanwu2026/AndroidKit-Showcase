# AndroidKit Showcase · Four-in-One Integration Example

> 🤖 This project was generated by AI.

[中文](README.md) | [English](README_EN.md)

A demo app that integrates three client SDKs in one project, showing four capabilities on one screen:

| Capability | Backend | SDK |
|---|---|---|
| License activation | OpenHub `cardkey` plugin | [CardKeySDK](https://github.com/wanwu2026/CardKeySDK) |
| Version updates | OpenHub `update` plugin | [UpdateKit](https://github.com/wanwu2026/UpdateKit) |
| Announcements | OpenHub `announce` plugin | [UpdateKit](https://github.com/wanwu2026/UpdateKit) |
| Crash reporting | OpenHub `crash` plugin | [CrashKit](https://github.com/wanwu2026/CrashKit) |

All three SDKs talk to the [OpenHub](https://github.com/wanwu2026/OpenHub) server.

## Dependencies (JitPack)

After tagging the three SDK repos:

```gradle
// settings.gradle
repositories { maven { url 'https://jitpack.io' } }
// app/build.gradle
dependencies {
    implementation 'com.github.wanwu2026:CardKeySDK:TAG'
    implementation 'com.github.wanwu2026:UpdateKit:TAG'
    implementation 'com.github.wanwu2026:CrashKit:TAG'
}
```

Replace TAG with a real version (e.g. `v1.0.0`). First publish requires signing in at https://jitpack.io with GitHub and triggering a build.

## Init (`ShowcaseApp`)

```java
CardKey.init(new CardKey.Config(this)
        .productId("my_app").publicKeyBase64(PUB).mode(CardKey.Mode.OFFLINE)); // throws — catch it
UpdateKit.init(new UpdateKit.Config(this)
        .baseUrl(OPENHUB_BASE).apiKey(KEY).product("my_app").publicKeyBase64(PUB));
CrashKit.init(new CrashKit.Config(this)
        .baseUrl(OPENHUB_BASE).apiKey(KEY).appId("my_app"));
CrashKit.get().install();
```

Private keys stay on the OpenHub server; clients embed only the public key.
